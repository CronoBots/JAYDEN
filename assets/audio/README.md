# Audio

Déposer ici l'extrait du single sous le nom exact :

```
somethin-inside-my-mind.mp3
```

Le lecteur de la page (section **Musique**) le détecte et le joue automatiquement,
sans aucune autre modification. Tant que le fichier est absent, le lecteur invite
simplement à écouter sur les plateformes (Spotify, Apple Music, YouTube).
